# 必应搜索多页爬虫 (Python)

## 项目简介
基于 Python 开发的必应搜索批量采集工具。支持自定义搜索关键词、起始页和终止页，实现多页数据自动抓取。

## 核心功能
- **自定义配置**：支持手动输入搜索关键词、起始页、终止页，灵活控制爬取范围。
- **多页自动爬取**：循环遍历指定页码，自动构造分页参数，批量获取多页搜索结果。
- **基础反爬防护**：随机切换 User-Agent 请求头，并设置 3-6 秒随机请求间隔，有效降低被网站封禁 IP 的风险。
- **稳定数据解析**：使用 BeautifulSoup 解析页面结构，精准提取搜索结果的标题与链接。

## 技术栈
- 语言：Python 3
- 网络请求：requests
- 数据解析：BeautifulSoup4
- 辅助工具：random, time
